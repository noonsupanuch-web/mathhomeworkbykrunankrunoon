📊 เชื่อมต่อฐานข้อมูลออนไลน์ (Google Sheets)

แอปนี้สามารถบันทึกข้อมูลออนไลน์ได้ฟรี! โดยใช้ Google Apps Script โปรดทำตามขั้นตอน:

  1. ไปที่ Google Sheets สร้างไฟล์ใหม่ว่างๆ
  2. เมนู ส่วนขยาย (Extensions) > Apps Script
  3. ลบโค้ดเดิมออกทั้งหมด แล้วก๊อปปี้โค้ดด้านล่างนี้ไปวาง
  4. กด นำไปใช้งาน (Deploy) > การนำไปใช้งานรายการใหม่ (New deployment)
  5. เลือกประเภทเป็น เว็บแอป (Web App), สิทธิ์เข้าถึงเป็น ทุกคน (Anyone) แล้วกด Deploy
  6. ก๊อปปี้ Web App URL นำมาวางในช่องด้านล่าง แล้วกดบันทึก
